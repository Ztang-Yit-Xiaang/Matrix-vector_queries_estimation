# Theorem 2: Sequential-Pilot Adaptive Hutch++ Unbiasedness

**Classification**: `PROVED`

**Notation**: See [`proof_notation.md`](proof_notation.md). In particular, $S$ is reserved for the sketching matrix, $B$ is the random stopped pilot size, and $J$ is the random stage index when that index is needed.

---

## 1. Theorem Statement

Let $A \in \mathbb{R}^{d \times d}$ be any square real matrix (not necessarily symmetric or PSD for unbiasedness).
Let $m$ be the total matrix-vector query budget.

Let $\{\mathcal{F}_{b_j}\}_{j=1}^{N_{\mathrm{stg}}}$ be the filtration generated by all observations and decisions up to pilot size $b_j$.
Assume the sequential pilot stopping time $B \in \{b_1, \dots, b_{N_{\mathrm{stg}}}\}$ is a random stopping time relative to $\{\mathcal{F}_{b_j}\}_{j=1}^{N_{\mathrm{stg}}}$.

After stopping, the algorithm may use additional sketch columns to extend the pilot basis. Let $\mathcal{G}$ be the **pre-residual sigma-algebra** generated by the stopped pilot, all basis-extension sketches and matrix-vector products, and all allocation decisions made before residual probes are drawn. In particular, the following objects are $\mathcal{G}$-measurable:
- Target sketch width $q = q_{\text{target}} \ge B$;
- Final sketch matrix $S=[S_{\mathrm{pilot}},S_{\mathrm{extra}}]\in\mathbb R^{d\times q}$;
- Final orthonormal basis $Q \in \mathbb{R}^{d \times r}$ with actual rank $r = r_{\text{actual}} \le q$;
- Residual probe count $\ell = m - q_{\text{target}} - r_{\text{actual}} > 0$.

Assume:
1. $Q$ has orthonormal columns ($Q^T Q = I_r$);
2. After all pilot and allocation decisions are complete, fresh residual probes $g_1, \dots, g_\ell$ are drawn;
3. The probes have finite second moments and satisfy $\mathbb{E}[g_j g_j^T \mid \mathcal{G}] = I_d$.

Define the orthogonal residual projector $R = I - Q Q^T$, and the estimator:
$$\widehat{t} = \operatorname{tr}(Q^T A Q) + \frac{1}{\ell} \sum_{j=1}^\ell g_j^T R A R g_j$$

Then, for any square real matrix $A$:
$$\boxed{\mathbb{E}[\widehat{t}] = \operatorname{tr}(A)}$$
unconditionally, even though $B, q, r, Q, \ell$ are random variables.

---

## 2. Complete Mathematical Proof

### Step 1: Conditioning on $\mathcal{G}$
Conditioning on $\mathcal{G}$ fixes $Q, R, q, r, \ell$, including any randomness used after the pilot stopping time to extend the basis.

For each fresh probe $g_j$, since $g_j^T R A R g_j$ is a scalar:
$$g_j^T R A R g_j = \operatorname{tr}(g_j^T R A R g_j) = \operatorname{tr}(R A R g_j g_j^T)$$

Taking conditional expectation:
$$\mathbb{E}[g_j^T R A R g_j \mid \mathcal{G}] = \operatorname{tr}\left( R A R \, \mathbb{E}[g_j g_j^T \mid \mathcal{G}] \right) = \operatorname{tr}(R A R I_d) = \operatorname{tr}(R A R)$$

### Step 2: Conditional Expectation of the Averaged Residual Term
Because $\ell$ is fixed conditional on $\mathcal{G}$:
$$\mathbb{E}\left[ \frac{1}{\ell} \sum_{j=1}^\ell g_j^T R A R g_j \;\middle|\; \mathcal{G} \right] = \frac{1}{\ell} \sum_{j=1}^\ell \operatorname{tr}(R A R) = \operatorname{tr}(R A R)$$

Thus:
$$\mathbb{E}[\widehat{t} \mid \mathcal{G}] = \operatorname{tr}(Q^T A Q) + \operatorname{tr}(R A R)$$

### Step 3: Trace Identities
Let $P = Q Q^T$. Because $Q^T Q = I_r$, $P^2 = P$ and $R = I - P$.
By trace cyclicity:
$$\operatorname{tr}(Q^T A Q) = \operatorname{tr}(A Q Q^T) = \operatorname{tr}(A P)$$

Also:
$$\operatorname{tr}(R A R) = \operatorname{tr}(A R^2) = \operatorname{tr}(A R) = \operatorname{tr}(A (I - P)) = \operatorname{tr}(A) - \operatorname{tr}(A P)$$

Summing both terms:
$$\mathbb{E}[\widehat{t} \mid \mathcal{G}] = \operatorname{tr}(A P) + \operatorname{tr}(A) - \operatorname{tr}(A P) = \operatorname{tr}(A)$$

### Step 4: Unconditional Expectation by Tower Property
By the law of total expectation (Tower Property):
$$\mathbb{E}[\widehat{t}] = \mathbb{E}\left[ \mathbb{E}[\widehat{t} \mid \mathcal{G}] \right] = \mathbb{E}[\operatorname{tr}(A)] = \operatorname{tr}(A)$$
$$\boxed{\mathbb{E}[\widehat{t}] = \operatorname{tr}(A)}$$
$\blacksquare$

---

## 3. Important Interpretation
No optional stopping theorem is required for unbiasedness. The essential sample-splitting requirement is:
$$\boxed{\text{all adaptive decisions occur before fresh residual probes are generated, and the probes remain conditionally isotropic given }\mathcal{G}.}$$
Pilot noise may increase variance by causing a poor allocation, but it does not introduce estimator bias.
