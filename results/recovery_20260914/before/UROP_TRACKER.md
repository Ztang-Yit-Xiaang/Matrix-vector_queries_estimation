## Paper Notes

### TurboQuant

- Paper: "TurboQuant: Online Vector Quantization with Near-optimal Distortion Rate"
- arXiv: https://arxiv.org/abs/2504.19874
- Local PDF: `TurboQuant/2504.19874v1.pdf`
- Local work: `TurboQuant/TurboQuant_implementation.ipynb`
- What the paper is about: TurboQuant studies online vector quantization for high-dimensional Euclidean vectors. The main goal is to reduce storage or communication while preserving geometry, especially mean-squared error and inner products. The approach uses random rotations so coordinates become well behaved, then applies scalar quantizers coordinate-wise. For inner products, the paper adds a residual 1-bit Quantized Johnson-Lindenstrauss step to reduce bias. The paper compares its distortion to information-theoretic lower bounds and reports applications such as KV-cache quantization and nearest-neighbor search.

### Uniform Sampling For Matrix Approximation

- Paper: "Uniform Sampling for Matrix Approximation"
- arXiv: https://arxiv.org/abs/1408.5099
- Local PDF: `leverage_score/1408.5099v1.pdf`
- Local work:
  - `leverage_score/leverageScore.ipynb`
  - `leverage_score/leverageScore_datasets_ready.ipynb`
  - `leverage_score/leverageScore_fair_benchmarks.ipynb`
  - `leverage_score/data_loaders.py`
  - `leverage_score/plot_helpers.py`
  - `leverage_score/report_figures/`
- What the paper is about: the paper studies row sampling for large matrix approximation. Leverage-score sampling gives strong guarantees but leverage scores can be expensive to compute. Uniform sampling is much simpler, and the paper analyzes what uniform sampling preserves even when it is too weak to solve regression directly. Its key idea is that uniform samples can preserve enough structure to support iterative approximation methods, and the theory includes a structural result showing that a matrix can be made low-coherence by reweighting a small subset of rows.
- Report note from shared "Bernoulli row-sampling comparison" chat: distinguish two Bernoulli leverage-sampling modes. The theorem-faithful mode uses probabilities `p_i = min(1, c log(d) u_i / epsilon^2)` and treats sample count as an output; this is the right default when claiming an implementation of the epsilon-based leverage-sampling algorithm. The fixed-budget mode chooses a scale `beta` so `sum_i min(1, beta u_i)` approximately equals a target row count; this is not the theorem's sampling rule, but it is useful as an experimental control when comparing methods at the same expected compression level.

## Report And Poster Material

- Motivation: large-scale matrix and vector problems need compressed or sampled representations that keep enough geometric information for downstream tasks.
- Methods to explain:
  - TurboQuant: random rotation, coordinate-wise scalar quantization, residual QJL correction for inner products.
  - Matrix approximation: leverage-score sampling versus uniform sampling, coherence, row sampling budgets, runtime/error tradeoffs.
  - Bernoulli leverage sampling: separate the theoretical epsilon-based experiment from the fixed-expected-row benchmarking experiment.
  - Oracle Local Threshold Theorem: under power-law decay $\lambda_i = i^{-c}$, exact finite-difference analysis of oracle MSE $F(k; c) = \frac{2}{m-2k} \sum_{i=k+1}^d i^{-2c}$ proves a unique threshold $c_k^* > 0$ ($H_k(c_k^*) = 0$) separating flat-spectrum regimes ($c < c_k^*$, favoring smaller $k$ / larger $\ell$) from steep-spectrum regimes ($c > c_k^*$, favoring larger $k$ / smaller $\ell$).
- Evidence currently available:
  - trace-estimation CSV/PNG results, benchmark scripts, tests, and mathematical proof notes in `Hutch++/Matrix-vector_queries_estimation/`;
  - leverage-score CSV summaries in `leverage_score/report_figures/`;
  - leverage-score PNG figures in `leverage_score/report_figures/`;
  - implementation and experiment notebooks in both project tracks.
- Report-ready comparison to include:
  - The epsilon-based sampler is the paper-faithful algorithmic result: as `epsilon` decreases, probabilities increase according to `c log(d) / epsilon^2`, so expected sampled rows, runtime, compression ratio, and approximation error should all be reported together.
  - The target-row sampler is a fairness control: by holding the expected number of retained rows fixed, it helps compare exact leverage scores, approximate leverage upper bounds, repeated halving/refinement methods, and uniform sampling without confusing better accuracy with simply keeping more rows.
  - Both samplers use the same unbiased rescaling `A_i / sqrt(p_i)`, so their methodological difference is only how `p_i` is chosen.
